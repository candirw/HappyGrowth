四种基本技法
直调 Build：直接在杯里加冰倒料。气泡类、口味清爽的都走这条。
摇和 Shake：入壶加冰摇 10–12 秒。含果汁、糖浆、蛋白的必须摇。
搅拌 Stir：加冰搅 20–30 秒。纯烈酒组合用搅不用摇。
分层 Layer：沿吧勺背面慢倒，靠密度差分层。
量酒器 15/30 怎么量
大头 30ml　小头 15ml　零头用吧勺补（1 勺 = 5ml）
20 = 小 + 1勺　25 = 小 + 2勺
40 = 大 + 2勺　45 = 大 + 小
50 = 大 + 小 + 1勺
60 = 大 ×2　90 = 大 ×3
100 = 大 ×3 + 2勺
120 = 大 ×4
量具换算
1 吧勺 bar spoon ≈ 5 ml
1 dash 苦精 ≈ 1 ml
1 茶匙 tsp ≈ 5 ml
1 盎司 oz ≈ 30 ml
1 个青柠出汁 ≈ 25–30 ml
冰块怎么选
大冰块：古典杯烈酒，化得慢，不稀释
方冰：highball 加满杯，冰越多化得越慢
碎冰：莫吉托、薄荷类，要快速降温
摇和用冰：普通方冰，摇完滤掉
通用顺序
1. 杯子先冰镇
2. 加冰至满
3. 先倒酒，后倒辅料
4. 气泡永远最后，沿吧勺注入
5. 酸（青柠/柠檬）最后挤，香气不跑
6. 只搅一到两次，护气泡
稀释控制
摇和 10–12 秒，壶身结霜即可
搅拌 20–30 秒
直调轻搅 1 次
冰少 = 化得快 = 变淡，宁可冰多
常见失败原因
• 汤力水／苏打水常温，气泡跑光
• 薄荷捣烂，整杯发苦
• 用牛奶代替淡奶油
• 盐边做全圈，越喝越咸
• 摇不够，酒不冰、口感发钝
