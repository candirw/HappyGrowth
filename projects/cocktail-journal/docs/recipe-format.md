# 配方格式说明

配方都在 `recipes.js`，是一个数组：

```js
window.RECIPES = [
  { ...配方1 },
  { ...配方2 }
];
```

照现有条目加一条即可，不用改任何代码。

---

## 完整字段

```js
{
  id: 'margarita',              // 唯一标识，英文小写加连字符
  name: '玛格丽特',              // 中文名（显示用）
  en: 'Margarita',              // 英文名
  base: '龙舌兰',                // 基酒分类，见下方可选值
  iba: true,                    // 是否为 IBA 官方配方，用于筛选
  abv: '约 27%',                // 稀释后估算酒精度
  difficulty: 2,                // 难度 1–3，显示为 ★★☆
  glass: '玛格丽特杯（需冰镇）',   // 杯型
  ice: '摇和用冰，出品无冰',      // 用冰方式
  method: '摇和 Shake',          // 技法
  time: '约 2 分钟',             // 耗时
  brief: '龙舌兰 50 / 君度 20 / 青柠 15',  // 一行配方，自动填入记录页

  ingredients: [                // 用料表
    ['龙舌兰', 50, '100% 蓝韦伯龙舌兰'],
    ['君度',   20, '橙味利口酒'],
    ['青柠汁', 15, '现榨']
  ],

  steps: [                      // 分步操作
    '青柠角擦湿杯口外沿半圈，蘸盐',
    '摇酒壶加冰至七分满',
    '倒入龙舌兰、君度、青柠汁',
    '摇 10–12 秒',
    '滤入冰镇好的杯，不加冰'
  ],

  garnish: '半盐边 + 青柠角',
  tips: ['盐边做半圈，喝的时候能对比……'],       // 关键点
  mistakes: ['盐边做全圈', '摇超过 15 秒，化水冲淡'] // 常见错误
}
```

---

## `base` 可选值

决定配方指南顶部的筛选分类，必须用下面之一：

```
伏特加 / 龙舌兰 / 朗姆 / 金酒 / 威士忌 / 白兰地 / 利口酒 / 味美思
```

新增分类要同时改 `index.html` 里筛选栏的按钮。

---

## `ingredients` 的三元组

```js
[用料名, 用量, 备注]
```

| 位置 | 类型 | 说明 |
|---|---|---|
| 0 | string | **用料名**——能不能做全靠它对上库存的 `covers` |
| 1 | number \| string | 数字会自动加 ` ml`；也可写 `'补满'`、`'适量'` |
| 2 | string | 备注（选酒建议 / 处理方式），可留空 |

### 用料名要和库存 `covers` 对齐

配方写 `'伏特加'`，库存那瓶的 `covers` 里就必须有 `'伏特加'`。

写 `'青柠汁'` 而不是 `'青柠'`——这些是**唯一允许的写法**，因为库存是按名字精确匹配的。

常用用料名清单：

```
伏特加 白朗姆 金酒 龙舌兰 威士忌 爱尔兰威士忌 白兰地
君度 卡鲁瓦 百利 帝萨诺 金巴利 干味美思 甜味美思
青柠汁 柠檬汁 糖浆 白砂糖 盐 冰
苏打水 汤力水 姜汁啤酒 可乐 橙汁 西柚汁 蔓越莓汁 石榴糖浆
淡奶油 薄荷叶 咖啡 冷萃咖啡 浓缩咖啡 蛋白 苦精
```

写清单外的名字，会被当成"未知用料"，那款配方永远显示缺料。

---

## `brief` 的作用

`brief` 会自动成为「快速记录」页的下拉预设。用户在记录页选「玛格丽特」，配方栏就自动填上这一行。

所以 `brief` 要写成人能一眼看懂的一行，不要照搬 `ingredients` 的结构。

---

## `difficulty` 的判断标准

| 星级 | 含义 | 例子 |
|---|---|---|
| 1 | 直调或简单摇和，几乎不会失败 | 螺丝起子、金汤力 |
| 2 | 需要摇和或搅拌，火候有讲究 | 玛格丽特、威士忌酸 |
| 3 | 分层、多步骤或有特殊技法 | B52 |

---

## `abv` 怎么估

不用精确，按体积加权算，再考虑稀释：

```
酒精度 ≈ Σ(各酒用量 × 各自酒精度) ÷ 成品总量
摇和 / 加冰出品再乘 0.8 左右（稀释）
```

写成 `约 XX%` 就好，别给到小数点后一位——那反而显得不可信。

---

## 加配方的两种情形

**加一款现成配方**：照抄一条，改 `id`、`name`、`ingredients`、`steps` 就行。

**改现有配方**：直接改数字，但建议在 `tips` 里记一句改了什么、为什么，方便以后回看。

---

## 检查清单

改完刷新页面，确认这几件事：

1. 配方出现在指南页
2. 筛选栏点对应基酒能筛到它
3. 展开后用料、步骤、关键点都渲染正常
4. 点「记录这一杯」能跳转并预填名称与 `brief`
5. 库存充足时标记显示「可做」，缺料时显示「差 N 样」

浏览器按 `F12` 打开控制台，有报错会在里面显示。
