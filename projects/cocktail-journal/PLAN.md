# PLAN

## 目标

做一个家庭调酒用的记录工具：喝完一杯能快速打分，攒够数据能看出自己到底偏爱什么，买酒前能知道"现有存货能做什么"。

## 范围

**做**

- 基酒 / 鸡尾酒两套八维打分
- 配方指南（含操作细节与常见错误）
- 按库存自动判定可做性
- 统计画像与 Markdown / JSON 导出

**不做**

- 账号体系、多端同步、云端存储
- 社交、分享、评论
- 商城、配方购买

## 为什么不做云同步

调酒记录是低频、私密、不值得为它引入后端的数据。localStorage + 定期导 JSON 足够，且零维护成本。真要跨设备，用户自己丢网盘即可。

同理，不做账号体系——单人工具引入登录只会增加使用门槛和数据风险。
