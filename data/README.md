# data/ · 计划系统的原始输入

> 只存**日聚合后**的结构化数据，不存原始高频数据（截图/秒级心率等分析完即弃，不入库）。

## 目录

```
data/
├── wearable/
│   └── YYYY-MM.csv    手环日聚合：date,sleep_min,deep_min,rem_min,resting_hr,steps,screen_min
└── screen/
    └── YYYY-MM.csv     屏幕使用时间（如与手环分开统计）
```

## 为什么是这个粒度

一行一天，一个月约 30 行 ≈ 2KB。AI 一次能读一整个季度而不超预算；全自动生成，零人工操作。
详见 `../docs/03_架构.md` §6。

## ⚠️ 隐私提醒：本仓库当前是 Public

这个目录一旦填入真实数据，**睡眠时长、静息心率、步数等个人健康信息会公开可见**。

在接入真实手环数据前，请先决定：
1. 把仓库切成 Private，或
2. 把 `data/` 拆到独立私有仓库 / 本地不入 git（仅保留本 README 说明格式）

默认已在 `.gitignore` 里排除 `*.csv`，只保留目录结构和本说明，**避免误提交**。真正要开始使用时，请显式决定是否取消排除。见 `../DECISIONS.md` ADR-011。
