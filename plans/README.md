## 复盘归因框架（固定四类，不能笼统说"坚持不够"）

| 归因 | 判据 | 解法 |
|---|---|---|
| ① 能力不足 | 中断点集中在开头 | 拆小 |
| ② 动机不足 | 有空闲但没开始 | 换目标/重定意义 |
| ③ 环境不利 | 中断点分散在全程 | 改场景 |
| ④ 精力不足 | **多个不相关计划同时下滑** | 先查上游（睡眠/精力），不改计划本身 |

诊断顺序：先判断是否④（多计划同时下滑）→ 是则查 `../data/`；否则按中断点位置判①②③。
